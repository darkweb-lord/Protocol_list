# Communication Protocols by Field

### Automotive Protocols
* **CAN (Controller Area Network):** Connects vehicle electronic control units (ECUs) and sensors.
* **LIN (Local Interconnect Network):** Complements CAN by managing low-speed, low-cost subsystems like mirrors or power windows.
* **FlexRay:** Delivers high-speed, deterministic communication for safety-critical systems like drive-by-wire.
* **MOST (Media Oriented Systems Transport):** Handles multimedia networking for vehicle infotainment devices.
* **Automotive Ethernet:** Adapts traditional Ethernet for high-bandwidth automotive applications like advanced driver assistance systems (ADAS).

### Industrial Automation Protocols
* **Modbus:** Connects industrial electronic devices, controllers, and sensors over serial or Ethernet lines.
* **PROFINET:** Provides real-time industrial Ethernet data exchange for automation components.
* **EtherCAT:** Maximizes Ethernet speed and synchronization for high-performance motion control.
* **EtherNet/IP:** Utilizes standard Ethernet technologies alongside the Common Industrial Protocol (CIP) for factory automation.
* **BACnet:** Automates and coordinates building management systems like HVAC, lighting, and access control.

### IoT & Wireless Protocols
* **MQTT:** Uses a lightweight publish-subscribe model for data-constrained IoT sensors.
* **CoAP (Constrained Application Protocol):** Translates web service interactions for resource-constrained internet devices.
* **Zigbee:** Creates low-power, low-data-rate wireless mesh networks for smart homes.
* **Z-Wave:** Focuses on low-energy radio waves for reliable smart home automation control.
* **LoRaWAN:** Links long-range, low-power wireless devices to regional or national cellular networks.
* **BLE (Bluetooth Low Energy):** Transfers short bursts of data between nearby power-sensitive devices.

### Web & Application Protocols
* **HTTP/HTTPS:** Transmits hypermedia files and secure web pages across the internet.
* **WebSocket:** Opens persistent, two-way interactive communication sessions between a browser and a server.
* **gRPC:** Links distributed applications securely and quickly using Google's Protocol Buffers.
* **GraphQL:** Queries APIs precisely to fetch exactly the data a client requests.

### IT, Networking & Infrastructure Protocols
* **TCP/IP:** Forms the foundational communication architecture powering the global internet.
* **DNS:** Maps human-friendly domain names to machine-readable IP addresses.
* **DHCP:** Configures network settings by automatically dispensing IP addresses to connected clients.
* **BGP (Border Gateway Protocol):** Routes data traffic across the core routing infrastructure of the internet.
* **SNMP (Simple Network Management Protocol):** Monitors, configures, and manages network hardware components.

### File Transfer & Storage Protocols
* **FTP/SFTP:** Moves files between systems over TCP networks securely or insecurely.
* **NFS (Network File System):** Allows users to access files over a network as if they were local.
* **SMB (Server Message Block):** Shares files, printers, and serial ports between computers on a local network.
* **iSCSI:** Bridges data storage facilities over standard IP networks to emulate local drives.

### Communication & Messaging Protocols
* **SMTP, IMAP, POP3:** Handles routing, delivering, retrieving, and syncing electronic mail.
* **SIP (Session Initiation Protocol):** Signals and controls real-time multimedia sessions like voice and video calls.
* **XMPP (Extensible Messaging and Presence Protocol):** Powers instant messaging, presence information, and multi-party chat rooms.
